# HOW TO USE
## Run and install locally
1. Install Python and Flask (`python -m pip install flask`) if they are not already installed.
2. Double-click `run_local.bat` and leave the server window open.
3. On the same computer, open `http://localhost:5000/download` in Chrome or Edge.
4. Select **INSTALL PWA**. If the browser does not show an install prompt, use its menu and choose **Install app**.

The PWA requires a web server; opening the HTML file directly will not work. `localhost` is allowed for local installation. To install on a phone or another computer, host the site over HTTPS and open that hosted URL on the device. The site must remain hosted for features or pages that are not cached offline.
